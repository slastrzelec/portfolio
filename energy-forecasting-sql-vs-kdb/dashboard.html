📊 Data Overview

London Smart Meter Project Dataset Contains energy consumption measurements (electricity and gas) for 4,443 households and businesses with 30-minute frequency throughout 2013. This analysis uses cloud infrastructure (AWS S3, Athena) and time series forecasting techniques.

Consumption Distribution

Histogram reveals significant disparity - most meters consume low energy, but a few (factories, large buildings) consume much more. Maximum annual consumption: 36,994 kWh.

Top 20 Consumers

The largest 20 meters account for ~15% of total consumption. MAC004179 (Industrial) consumes 37K kWh - clearly a factory or large facility.

🏢 Meter Segmentation

Three Main Categories: Meters segmented into Residential (homes), Commercial (offices), and Industrial (factories) based on consumption patterns. Distribution is nearly even across categories (~33% each).

Number of Meters per Segment

Each segment contains ~1,365 meters. This demonstrates a well-diversified energy market between residential, commercial, and industrial consumers.

Average Consumption by Segment

Industrial: 6,478 kWh - 4x higher than Commercial (3,099 kWh). Residential: 1,549 kWh. Significant differences across segments.

🔧 Technical Architecture & Methodology

AWS Cloud Infrastructure:
  • Amazon S3: Raw data storage (587 MB CSV file)
  • Amazon Athena: Serverless SQL queries on S3 data without downloading
  • No EC2/Compute: Fully managed, cost-effective solution
  • Query Performance: Sub-second queries on 4.4M data points
SQL Analysis (Athena):
  • Aggregations: SUM, AVG, MAX, MIN, STDDEV for consumption metrics
  • String Functions: SUBSTR for date parsing (YYYY-MM-DD extraction)
  • Set Operations: UNION ALL to combine results from multiple meters
  • Filtering: WHERE clauses to handle NULL values and data quality
  • Sorting: ORDER BY for ranking and TOP-N analysis
Time Series Forecasting (Python/StatsModels):
  • Prophet: Facebook's forecasting library with built-in seasonality detection
  • Decomposition: STL decomposition into Trend + Seasonal + Residual components
  • Stationarity Test: Augmented Dickey-Fuller (ADF) test for data suitability
  • Anomaly Detection: Z-score and IQR (Interquartile Range) methods
  • Validation: Train-test split (80/20) with MAE metric
Data Pipeline:
  • Raw Data (S3) → SQL Analysis (Athena) → Python Processing → Visualization (Plotly)
  • All computations happen in AWS cloud
  • Only final aggregated results downloaded locally

💡 Key Business Insights

1. High Consumption Inequality Pareto principle evident - top 20 meters (0.45%) consume 15% of total energy. Market optimization should target large industrial consumers.
2. Strong Seasonality Energy consumption highly weather-dependent. Winter: 0.8 kWh/day, Summer: 0.3 kWh/day. Peak in February (extreme cold), secondary peak in November (season transition).
3. Distinct Consumption Profiles Residential: stable, low volatility (ideal for fixed pricing). Commercial: declining trend (efficiency gains). Industrial: high volatility, difficult to predict (requires dynamic pricing).
4. Forecast Accuracy Varies Prophet achieves MAE 0.036-0.495 depending on segment. Smaller meters (Residential) are 10x more predictable than Industrial. Useful for demand forecasting and inventory planning.
5. Automated Anomaly Detection Feasible 8 anomalous days detected automatically. IQR + Z-score methods show 87.5% agreement. Can implement real-time alerts for unusual consumption patterns.
